# SlashTripwires
Very simple paper plugin

## Commands

```/tripwires```: Gives you a full inventory of tripwire hooks

# Requirements:
- Java 21
- Paper 1.21.11 server (change api-version in paper.yml when building for less)
- Gradle

# Setup

1. Clone / Download the git
2. Build it:
  ```
  # Windows
  gradlew.bat build
  # If doesnt work use below for powershell
  # Linux/Mac
  ./gradlew build
  ```
